# Prompt Radar

Инструмент аналитики запросов к корпоративным ИИ-агентам для кейса КРОК на
Nuclear IT Hack School.

Prompt Radar превращает сырые логи в понятную для CTO картину:

- какие типы задач сотрудники отдают ИИ;
- какие устойчивые сценарии использования появились;
- какие сценарии растут;
- где пользователи или агенты сталкиваются с проблемами;
- что выгоднее автоматизировать или улучшить первым.

## Стек

- Next.js 16, React 19, TypeScript
- Tailwind CSS 4 и собственные дизайн-токены
- Zod для контракта данных
- PapaParse для корректного разбора многострочного CSV
- Vitest для алгоритмов и контрактов
- внешние embedding/chat API через обычный `fetch`

Тяжёлые ML-библиотеки и база данных не входят в MVP. Большой CSV разбирается в
браузере, вычисления выполняются батчами, а в API передаются только компактные
семантические представления запросов.

## Быстрый старт

Требуется Node.js 22+.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Открыть <http://localhost:3000>.

Для checkpoint-демонстрации открыть
<http://localhost:3000/checkpoint>. Первый расчёт обрабатывает 1 500 событий,
последующие запросы используют кэш процесса.

Воспроизводимая генерация синтетического operational log:

```bash
npm run generate:dataset
```

Проверка перед передачей изменений:

```bash
npm run check
npm run build
```

## Принцип анализа

Полный запрос может достигать 100 тысяч токенов. Перед классификацией из него
строится компактная Intent Capsule: действие, объект, системы, периодичность,
формат результата и аудитория. Классификация и кластеризация работают по этой
капсуле, а не по приложенным письмам или документам.

Экономическая методика разделяет Potential Value, Realized Value и Value Gap.
Формулы и ограничения описаны в
[`docs/methodology.md`](docs/methodology.md), сценарий показа — в
[`docs/checkpoint.md`](docs/checkpoint.md).

## Переменные окружения

Проект использует OpenAI-compatible HTTP API, но не привязан к конкретному
провайдеру.

```dotenv
AI_BASE_URL=
AI_API_KEY=
AI_CHAT_MODEL=
AI_EMBEDDING_MODEL=
```

Без ключа интерфейс запускается на демонстрационных данных.
